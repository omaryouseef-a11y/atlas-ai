# Contributing

Contributions should improve this public legacy/reference implementation without importing private production code or configuration.

1. Open an issue describing the legacy concept or defect.
2. Create a focused branch.
3. Add offline tests for behavior changes.
4. Run the checks in `docs/DEVELOPMENT.md`.
5. Confirm the contribution contains no credentials, personal data, generated media, private infrastructure details, or unlicensed assets.

Provider changes must remain optional, fail clearly when not configured, and use mocked tests. Do not add automatic publishing or deployment workflows.

No open-source license has been selected yet. Discuss substantial contributions with the repository owner before investing work; public visibility alone does not grant reuse rights.
