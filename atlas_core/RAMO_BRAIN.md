## 3. Crucial Lessons Learned
- **The Delegation Mistake**: We once allowed the Video Agent to generate prompts directly without a QA check, causing duplicate API calls and wasted money.
- **The Fix**: We built the Triple Lock (Job Manager, QA Gate, Asset Vault). Now, the Orchestrator MUST approve every API call.
- **The Narrative Shift**: Episode 001 originally lacked a strong educational hook. Omar pivoted us to V2: A fast-paced, cumulative counting story (1 to 10) where characters join the frame one by one.
